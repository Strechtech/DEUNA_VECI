## Instrucciones de ejecución.❗
La aplicación se realizó utilizando React Native y Expo SDK 57. Se requiere Node.js LTS y npm.

### Instalación y ejecución 🚩
Desde la carpeta de la aplicación, instala las dependencias y arranca Expo:
```bash
npm install
npx expo start
```

Si la conexión Wi-Fi impide que el teléfono alcance Metro, inicia con túnel:
```bash
npx expo start --tunnel
```

### Instalación en dispositivo 📱:
- Actualiza Expo Go desde la tienda de aplicaciones para que sea compatible con SDK 57 y escanea el QR que muestra Expo.
- Para abrir en un emulador de Android, instala Android Studio y configura Android SDK; luego inicia Expo y presiona `a`. Esto requiere el SDK local y es independiente del uso de Expo Go en un teléfono.

## Recomendaciones 🔧.
No enviar demasiadas consultas al chatbot por el límite de tokens para la API.
